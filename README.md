# Cửa hàng Thuốc BVTV Lí An — Interactive 3D Ghibli Diorama

Mô hình 3D tương tác phong cách **Studio Ghibli** của **Đại lý Vật tư Nông nghiệp Lí An**.

## Tính năng nổi bật
- **Cửa hàng & Kho phân bón dài 30m** với đầy đủ quầy `hoptri summit`, tủ `BAYER` / `HB-101`, sảnh rổ thuốc BVTV, đồng hồ treo tường chạy **thời gian thực**, kho phân bón 3 tầng, ánh nắng giếng trời và tính năng **Mở mái (`I`)** xem nội thất.
- **Khu sinh thái Vườn Bonsai Lí An** phía sau nhà mái ngói: 10 cây bonsai trồng trực tiếp trên gò rêu & đá cuội, hồ cá Koi hoa sen, lối đá bước dạo và giàn dây leo.
- **Cảnh quan miền Tây:** hàng cau thẳng tắp, cây dừa 3 tầng tán xòe 3D, ruộng lúa, dàn nhân vật 3D có hoạt ảnh xương.
- **3 chế độ ánh sáng (`N`):** Ban ngày (mây Ghibli + mặt trời) · Hoàng hôn · Ban đêm (sao trời, đèn đường, đom đóm).
- **Chế độ Đóng vai Khách hàng (`T`):** đi dạo góc nhìn thứ 3 hoặc thứ 1 (`V`) bằng `WASD` / phím mũi tên / D-Pad, tương tác chọn mua thuốc & thanh toán tại quầy (`E`).

## Phím tắt
| Phím | Chức năng |
| --- | --- |
| `T` | Bật / tắt chế độ đóng vai khách hàng |
| `V` | Đổi góc nhìn thứ 3 / thứ 1 (trong chế độ `T`) |
| `E` | Xem kệ hàng / Thanh toán tại quầy |
| `N` | Chuyển Ban ngày · Hoàng hôn · Ban đêm |
| `I` | Mở / đóng mái kho xem nội thất |
| `Space` | Tạm dừng / tiếp tục hoạt ảnh |
